# Tesla Companion 🚗

A personal project to monitor and visualize Tesla vehicle data.

The goal is to build a dashboard to explore vehicle information such as:

- Battery state of charge (SOC)
- Estimated driving range
- Odometer
- Charging history
- Energy consumption and efficiency
- Vehicle status and health

## Tech Stack

- Python / FastAPI – Backend and API integration
- PostgreSQL – Data storage
- Grafana – Data visualization
- Docker Compose – Local development environment
- Tesla Fleet API – Vehicle data integration
